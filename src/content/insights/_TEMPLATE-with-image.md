This is a template showing how to write an article with a featured image.

To use an image:

Add the `image:` line to the frontmatter above, pointing to a file in your `public/articles/` folder.

Add a matching `imageAlt:` line describing the image.

Upload the actual image file to `public/articles/` in your repo.

If you leave out the `image:` line entirely, the article simply has no image — exactly like your existing posts. Images are always optional.
